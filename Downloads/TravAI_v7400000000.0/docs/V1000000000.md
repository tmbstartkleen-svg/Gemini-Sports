# TravAI v1000000000 — Sovereign Hybrid Intelligence

Adds a persistent local-first intelligence router above the existing TravAI engineering stack.

## Core capabilities
- Local Ollama remains the default inference path.
- Optional OpenAI-compatible cloud providers can be configured without storing API keys in TravAI files.
- Provider health checking, latency tracking, automatic failover and route evidence.
- Automatic cloud escalation for low-confidence, current/web, complex or explicitly cloud-routed work.
- Cloud use can be disabled entirely.
- Context sent to cloud providers is bounded by policy.
- Existing v500M guarded coding tools and approval gates remain unchanged.

## Credentials
Set secrets in the shell environment, for example:

`export TRAVAI_CLOUD_API_KEY='...'`

Do not place secrets in configuration JSON or source files.
