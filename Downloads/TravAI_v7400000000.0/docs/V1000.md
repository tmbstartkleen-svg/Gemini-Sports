# TravAI v1000 — Autonomous Engineering Loop

v1000 extends the v750 multi-agent engine with a governed engineering loop. It does not grant unrestricted shell autonomy. Instead it creates reversible artifacts inside `workspace/v1000`, tests them deterministically, performs bounded repair passes, verifies acceptance quality, and records the run into a persistent project-memory graph.

## New API
- `GET /api/v1000/control`
- `POST /api/v1000/runs`
- `POST /api/v1000/runs/action`
- `POST /api/v1000/settings`
- `POST /api/v1000/benchmark`
- `GET /api/v1000/memory-graph`
- `GET /api/v1000/events`
- `POST /api/v1000/self-test`

## Agents
Orchestrator, Planner, Researcher, Engineer, Tester, Critic, Verifier, Archivist.
