# TravAI v4000000000 — Elite Memory + Workstation OS

v4B makes offline operation the foundation of TravAI. It adds persistent personal/project memory, local knowledge indexing, workstation awareness, governed Mac actions, plugin manifests, and encrypted continuity without removing the v3B Tool + Connector OS, v2B Model Orchestrator, v1B Hybrid Intelligence, or the engineering stack beneath them.

## Core systems

- Five memory classes: episodic, semantic, project, procedural, preference
- Token-semantic recall with importance/confidence/use reinforcement
- Memory relationship graph and bounded compaction
- Local `knowledge/` index for notes, manuals, code, JSON, CSV, Markdown and configuration text
- Workspace inventory, system telemetry, process inventory, and macOS application inventory
- Approval-gated workstation actions with workspace confinement and soft-trash behavior
- Permission-declaring plugin manifest discovery under `plugins/`
- AES-256-GCM encrypted offline memory export/import under `sync/`
- Append-only memory/workstation audit ledger

## Workstation safety

v4B intentionally does not expose an arbitrary shell endpoint. Workstation operations are allowlisted. File mutations are confined to TravAI's workspace, destructive delete is replaced with a local `.travai-trash`, and consequential operations require explicit approval.

## Offline-first architecture

All v4B memory, local knowledge, workstation telemetry, plugin discovery and encrypted continuity work without an internet connection. Online capability remains additive through v3B/v2B/v1B when available.
