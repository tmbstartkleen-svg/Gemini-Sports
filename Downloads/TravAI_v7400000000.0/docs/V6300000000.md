# TravAI Elite v6.3B — Coding + Workstation Intelligence

v6.3B is an optimization release built on the stable v6.2.1B Elite shell. It adds a bounded local-project census, declared-test inventory, Git-state awareness, local Ollama role ranking for coding/review/repair, offline coding parity scoring, and approval-gated execution planning.

## Safety boundaries
- Project discovery is bounded to `workspace/`.
- No arbitrary shell endpoint is introduced.
- Mutation remains delegated to the existing approval-gated coding/operator layers.
- Verification planning prefers project-declared scripts.
- Every execution plan includes regression and checkpoint/rollback stages.
