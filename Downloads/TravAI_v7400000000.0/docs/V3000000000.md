# TravAI v3000000000 — Tool + Connector OS

The v3B layer gives TravAI a governed external-action boundary above the v2B Model Orchestrator. It introduces explicit connectors, scopes, approval rules, action planning, execution evidence, and an append-only audit trail.

## Built-in connectors
- Local Files: list/read directly; writes require approval. Paths are constrained to `workspace/`.
- Local Git: status/log/diff directly; branch creation and commits require approval. No generic shell tool is exposed.
- Web Read: HTTPS GET only. Private/local network targets are blocked.
- GitHub API: optional and disabled by default. The token is read only from `GITHUB_TOKEN`; write scopes require approval.

## Security boundary
Secrets are never stored in connector state. External requests are size/time bounded. Private-address targets are blocked. Write actions are represented as staged actions and cannot execute before approval. Every plan, approval, denial, and execution is audit logged.
