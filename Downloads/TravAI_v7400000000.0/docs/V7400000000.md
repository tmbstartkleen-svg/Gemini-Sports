# TravAI Elite v7.4 — Autonomous Agent Workspace

## Mission lifecycle
1. Scope
2. Gather evidence
3. Plan
4. Human approval barrier
5. Bounded execution
6. Verification
7. Independent review
8. Release/rollback evidence

## Reliability
Mission state is persisted locally. Tasks carry dependencies, bounded retry counts, evidence records, and checkpoints. Missions can be paused and resumed.

## Safety
- offline-first
- no arbitrary shell added
- no silent consequential mutation
- explicit human approval barrier
- bounded mission/evidence history
