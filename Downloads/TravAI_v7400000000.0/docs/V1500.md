# TravAI v1500 — Sovereign Engineering OS

v1500 adds file-aware project analysis, reversible patch sets, regression gates, model routing profiles, and a persistent code knowledge graph.

## API
- `GET /api/v1500/control`
- `POST /api/v1500/projects/analyze`
- `POST /api/v1500/patches`
- `POST /api/v1500/patches/action`
- `POST /api/v1500/regression/run`
- `POST /api/v1500/benchmark`
- `GET /api/v1500/knowledge-graph`
- `POST /api/v1500/settings`
- `POST /api/v1500/self-test`

## Patch lifecycle
proposed → approved → applied → rolled-back (optional)

Every apply creates a rollback manifest and copies replaced files into `workspace/v1500/rollback/<patch-id>`. New files are recorded so rollback can delete them.
