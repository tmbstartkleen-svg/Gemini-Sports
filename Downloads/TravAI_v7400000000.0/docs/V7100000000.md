# TravAI Elite v7.1 — Deep Local Knowledge + RAG

v7.1 strengthens the **Know** capability with offline, source-grounded retrieval.

## Capabilities
- local text/code/document indexing with bounded file and chunk limits
- exact line-range citations
- SHA-256 provenance digests per indexed file
- project-scoped workspace roots
- memory-aware retrieval with documentary evidence kept separate from memory context
- sensitive filename exclusion before content is read
- optional local Ollama synthesis grounded only in retrieved evidence
- persistent index and query history

## Safety and privacy
- indexing and retrieval are offline-first
- no cloud synthesis is used by the v7.1 engine
- `.env`, private-key, credential, token, and secret-like files are excluded by name
- workspace scopes cannot escape the TravAI workspace root
- retrieval never mutates project files
