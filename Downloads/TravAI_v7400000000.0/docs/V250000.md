# TravAI v250000 — Sovereign Continuous Operating System

v250000 adds an executive operating layer above the v100000 Continuous Company engine.

## New systems

- Company objectives / OKRs with approval and measurable progress.
- Portfolio resource allocation with protected incident and maintenance reserves.
- Incident command with detection, approval-gated response, timelines, and verified resolution.
- Technical-debt economics: principal, interest rate, blast radius, and annualized cost.
- Coordinated multi-product release calendar with quality/security/reliability/rollback gates.
- Deterministic strategy simulation for portfolio value, risk, and delivery confidence.
- Persistent operating-cycle history and company learning.
- 12-role executive and engineering operating team.
- A top-level `Run Operating Loop` workflow that performs observe → price risk → allocate → plan releases → measure objectives → simulate strategy → learn.

## Governance

v250000 retains human control. Incidents must be approved before resolution, debt paydown must be approved before retirement, and releases must be approved before completion. Existing v100000 and earlier engines remain available.
