# v6.2.1B — Elite UI Stability + Capability Upgrade

The primary UI was rebuilt as one deterministic shell with one external JavaScript controller. The historical v6.2 page is retained as `public/legacy-v620.html`, but it no longer auto-boots as the main UI. This eliminates competing legacy initialization timers and prevents raw JavaScript from appearing in the visible document.

macOS memory reporting now uses `vm_stat` to include inactive, speculative, and purgeable pages in available memory rather than presenting low `os.freemem()` as 100% used.
