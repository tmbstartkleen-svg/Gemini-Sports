# TravAI v10000 — Sovereign Program OS

v10000 adds a governed multi-repository product program layer above the v5000 development organization.

## Major systems
- Multi-repository product blueprints and dependency contracts
- Ten-role product organization
- Parallel feature campaigns with explicit dependencies
- Approval-gated whole-product execution
- Repository-level verification and aggregate quality scoring
- Bounded automatic repair campaigns
- Security and reliability release gates
- Coordinated release trains with rollback evidence
- Persistent event/evidence ledger
- Backward-compatible v5000/v3000/v2000/v1500/v1000/v750/v500 APIs

## Primary API
- `GET /api/v10000/control`
- `POST /api/v10000/programs`
- `POST /api/v10000/programs/action`
- `GET /api/v10000/release-trains`
- `POST /api/v10000/self-test`

The `build-whole-product` action performs the governed lifecycle from approved program through implementation, verification, repair if needed, and release-train promotion.
