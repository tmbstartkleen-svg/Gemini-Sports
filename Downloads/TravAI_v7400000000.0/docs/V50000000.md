# TravAI v50000000 — Sovereign Code Intelligence

Adds repository-wide symbol/call graphs, failure localization, test-impact analysis, bounded repair cycles, role-specialized local Ollama routing, approval-gated multi-file patches, snapshots, declared-script verification, and rollback.

## Safety model
- Repositories are confined to the TravAI workspace.
- File-changing patches require explicit approval.
- Only declared `test`, `check`, `lint`, `build`, or `verify` package scripts may execute through this layer.
- There is no arbitrary-shell API in the v50000000 engineering layer.
- Repair cycles are bounded to four passes.
