# TravAI v20000 — Sovereign Evolution OS

TravAI v20000 extends the v10000 Sovereign Program OS into a governed multi-release engineering system.

## New capabilities

- Multi-release product roadmaps with persistent evolution history.
- Isolated feature/change campaigns represented as governed branch plans.
- Specialized coding, review, regression, security, merge, release, and memory roles.
- Role-specific local-model routing profiles.
- Review scores and regression/security evidence before merge.
- Bounded automatic repair passes when release quality misses its gate.
- Dependency-ordered merge orchestration.
- Release promotion artifacts with rollback evidence.
- One-command `evolve-product` workflow that plans, implements, reviews, repairs, merges, and promotes the next release.
- Backward-compatible APIs for v10000, v5000, v3000, v2000, v1500, v1000, v750, and v500.

## API

- `GET /api/v20000/control`
- `POST /api/v20000/products`
- `POST /api/v20000/products/action`
- `POST /api/v20000/releases/action`
- `POST /api/v20000/self-test`

All generated work is bounded to the local TravAI workspace. Approval is required before product evolution and release execution.
