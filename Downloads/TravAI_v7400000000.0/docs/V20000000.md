# TravAI v20000000 — Sovereign Repair Intelligence

This release adds a repository-aware repair intelligence layer above v10000000.

## New systems
- Dependency and reverse-dependency graph
- Blast-radius scoring for proposed file changes
- Failure parsing and evidence-ranked diagnosis
- Test-impact analysis tied to declared project scripts
- Role-based local Ollama advice and model routing
- Bounded multi-pass repair loops
- Approval-gated patches with snapshots and rollback
- Persistent diagnoses, repair loops, memories, and evidence events

## Safety / governance
TravAI v20000000 does not expose arbitrary shell execution. Verification is restricted to declared package.json scripts in the allowlist: test, check, lint, build, and verify. File-changing actions require approval by default and are snapshot-backed.
