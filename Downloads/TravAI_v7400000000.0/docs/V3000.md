# TravAI v3000 — Sovereign Software Factory

TravAI v3000 adds a governed software-factory layer above v2000.

## New systems
- Idea-to-project factory runs
- Nine-stage execution graph from specification through release packaging
- Approval-gated project materialization
- Deterministic quality gates
- Bounded repair-loop records
- Governed multi-file change sets
- Snapshot-before-apply behavior for change sets
- Generated runnable starter applications inside the TravAI workspace
- Release artifact generation
- Full compatibility with v2000, v1500, v1000, v750, and v500 APIs

All generated project work remains inside the TravAI governed workspace unless the user explicitly exports it.
