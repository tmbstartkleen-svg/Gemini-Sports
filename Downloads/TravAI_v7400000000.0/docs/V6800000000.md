# TravAI Elite v6.8B — Native Mac Operator + Offline Capability Expansion

v6.8B adds a typed native workstation control layer above the existing offline-first coding, memory, repository intelligence, and governed engineering systems.

## Native Mac capabilities
- Discover installed macOS applications
- Open only discovered applications
- Reveal workspace items in Finder
- Create/copy/move/soft-trash workspace items
- Local macOS notifications
- Process inventory and approval-gated SIGTERM
- Keychain service/account references without returning secret values

## Safety model
- No arbitrary shell endpoint
- Consequential actions are staged before execution
- Explicit approval required before execution
- File mutations are confined to TravAI `workspace/`
- Deletes are soft-trash moves into `workspace/.travai-trash/`
- Keychain values are never returned through the v6.8 API
- TravAI remains bound to localhost by default

## Integrated offline stack
v6.8B also packages the v6.7 unified engineering loop, v6.6 repository intelligence, v6.5 coding team, a local v6.4 model tournament, memory/workstation intelligence, connector governance, model orchestration, and the always-on runtime.
